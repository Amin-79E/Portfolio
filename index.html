RAG · Localshipped
Local RAG Restaurant Review Assistant

A fully local retrieval-augmented Q&A system over restaurant reviews — Ollama running llama3.2 3B with mxbai-embed-large embeddings, Chroma for the vector store, LangChain gluing it together. Answers questions from a CSV of reviews through a terminal loop.

Fine-tuning · LLMv1.2
Python Tutor — fine-tuned code debugger

qwen2.5-coder:7b fine-tuned via Unsloth (QLoRA on Colab) to rate and debug submitted Python code from real error output rather than executing it. Benchmarked against the base model — the clearest gain was on requirement-based debugging (edge cases, "return the second-largest" style specs).
